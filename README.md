# Distinct Corporate Solutions website

Marketing site for Distinct Corporate Solutions, built with Astro and Tailwind CSS.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # output in ./dist
```

- Content (programmes, trainers, clients, photos): `src/data.ts`
- Phone, email, contact form key: `src/consts.ts`
- Hosting and domain setup: [`DEPLOY.md`](DEPLOY.md)
